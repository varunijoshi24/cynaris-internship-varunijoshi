# NumPy Fundamentals

## Project Overview

This project demonstrates fundamental NumPy concepts for Machine Learning as part of the AI/ML internship.

## Topics Covered

- Creating 1D, 2D, and 3D arrays
- Checking array shapes and dimensions
- Vectorized arithmetic operations
- Broadcasting
- Matrix multiplication
- Calculating mean and standard deviation
- Calculating correlation
- Working with CSV and Iris datasets

## Technologies Used

- Python
- NumPy

## How to Run

1. Install Python.
2. Install NumPy using `python -m pip install numpy`.
3. Run `numpy_fundamentals.py`.
